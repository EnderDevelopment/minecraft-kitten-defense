# Steal a Kitten! Minecraft Plugin

Steal a Kitten! is a base-defense collection simulator for Minecraft. Players own a base plot where kittens wander the center field. Collecting kittens and bringing them back to your base generates cash per second based on their rarity (Common, Rare, Epic, Legendary, Mythic, Secret). Players can also steal kittens from unlocked enemy bases, but be warned, getting tagged drops your kitten. Bases can be locked for 60 seconds per lock purchase, but expired locks leave you vulnerable. The plugin includes systems for data saving, a shop for upgrades, a rarity-weighted spawn table, an index/collection UI, daily rewards, a codes system, and hourly "Golden Rain" events.

## Install

1. Download the latest release from the [GitHub releases page](https://github.com/EnderDevelopment/Steal-a-Kitten/releases).
2. Place the downloaded JAR file in your server's `plugins` folder.
3. Restart your server or use the command `/reload` to load the plugin.

## Use

1. **Base Management**: Use the `/base` command to manage your base.
2. **Kitten Collection**: Use the `/collect` command to collect kittens.
3. **Shop**: Use the `/shop` command to open the shop and purchase upgrades.
4. **Codes Redemption**: Use the `/codes` command to redeem codes for special items or upgrades.
